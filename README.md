# 侵食大会アウトライン

Minecraft Java Edition **1.18.2 / Fabric** 用のクライアントMODです。
設定した基準Xから東西に11ブロック間隔の区画を作り、足元を含む区画を南北方向のガイドで表示します。

## 導入

旧版を使っている場合は、ゲームを終了し、`mods` 内の旧 `shinshoku-outline` JARを外して新版に置き換えてください。同じMODの旧版と新版を同時に入れないでください。

1. Minecraft 1.18.2 用の Fabric Loader **0.15.11以上**を用意します。
2. **Fabric API 0.77.0+1.18.2** と `shinshoku-outline-1.6.0+1.18.2.jar` を、そのゲーム環境の `mods` フォルダーへ入れます。
3. Fabricのプロフィールで起動してワールド・サーバーへ入ります。

Java 17以上が必要です。サーバー側への導入は不要です。
自動採掘・移動・サーバーへのコマンド送信は行わず、ガイドを描画します。

Fabric Installer: https://fabricmc.net/use/installer/
Fabric API（1.18.2向けファイル）: https://modrinth.com/mod/fabric-api/versions?g=1.18.2

## 操作

| キー | 動作 |
|---|---|
| O | ガイドの表示・非表示 |
| P | 設定画面を開く |
| G | 現在のX列・Y段を固定／自動選択に戻す |

キーはMinecraftの「設定 → 操作設定 → キー割り当て → 侵食大会アウトライン」で変更できます。

初期状態は**自動選択**です。足元のX・Y座標が含まれる枠を選びます。高さは選択モードに従います。
10段モードでのYの下端は `10 × floor((足元Y − 1) / 10) + 1` です。例えば足元Yが70なら61～71の枠、71以上81未満なら71～81の枠を選びます。
下端を含み、上端を含まない範囲として判定します。Xの共有境界ではXが大きい側の枠へ切り替わります。
**G** で現在の枠に固定し、もう一度押すと自動選択に戻ります。
**P** の設定画面ではX・Yを直接入力したり、「前列／次列」「下段／上段」で調整し、「入力したX・Yで固定」を押せます。
入力を変えただけでは固定されません。「足元を含む枠を自動選択」で自動に戻せます。
ワールド移動・再接続後は自動選択に戻ります。

## 立ち位置との差の表示

座標表示がONのとき、立ち位置との差は0付近でも常に表示します。
**P →「差の小数」**をクリックすると、小数点以下の桁数を **0～6桁**で切り替えられます（初期値2桁）。
設定はX・Yの差に適用され、保存されます。0桁は整数表示です。
ガイド非表示・座標表示OFF・F1による非表示、または対象の段がない場合の表示制御は従来どおりです。

## 基準Xの変更

**P →「基準X設定」**で変更します。基準は11ブロック間隔の立ち位置の一つで、初期値は **−1487.5** です。

- 数値を入力して「適用」：基準Xから東西両方向へ11ブロック間隔で区画を設定します。
- 「現在のX座標を基準にする」：現在いるブロックの中央を基準に設定します。
- 「元の値にリセット」：−1487.5に戻します。元のExcelの座標に一致し、その外側にも区画が続きます。

枠をブロック境界に合わせるため、入力値・現在地は `floor(X)+0.5` にそろえます。例：X=100.2なら100.5、X=−0.1なら−0.5です。
変更は即座に適用・保存されます。入力しただけで「戻る」を押した場合は適用されません。
基準を変えると自動選択・固定するXの入力・HUD・黄色と水色の枠が同じ座標にそろいます。固定中は選択列の番号を維持して移動します。
Yの段・採掘モードは変わりません。基準の左右に列数の制限はなく、元のExcelの端を越えても自動選択が続きます。初期基準でも同じ動作です。

## 採掘モード

**P →「モード」ボタン**で「10段」と「11段+ちーめぐ」を切り替えます。選択は保存され、次回起動時も維持します。初期設定は従来の「10段」です。

| モード | 段の下端Y | 高さ |
|---|---|---|
| 10段 | …−59、−49、−39、−29…（10n+1） | すべて10 |
| 11段+ちーめぐ | −59 | 最下段だけ10 |
| 11段+ちーめぐ | −49、−38、−27、−16、−5、6、17… | その上は11 |

新モードの最下段はブロックY=−59～−50（枠の境界は−59～−49）、次の段はY=−49～−39（枠の境界は−49～−38）です。
自動選択は下端を含み、上端を含みません。足元Y=−49では2段目に切り替わります。
幅は両モードとも11、黄色の立ち位置は幅1×高さ2です。
高さ11の段では黄色の枠を段の下端から1ブロック上に表示します。例：段の下端Y=-49なら黄色の枠はY=-48～-46です。高さ10の段（新モードの最下段を含む）は下端から表示します。
設定画面のY入力は「段の下端Y」です。HUDの「足Y」と立ち位置との差は、黄色の枠の下端を基準に表示します。
「11段+ちーめぐ」ではY=−59未満は対象外となり、自動選択の枠を非表示にします。
固定中のモード切替では、固定していたYを含む新モードの段に合わせます。自動選択中は現在の足元に合わせます。
設定画面の入力Yも新モードの有効な段に合わせます。入力だけでは固定されない点は従来どおりです。

## 表示範囲

- **水色**：立ち位置のブロックを含めてX方向に左右5ブロックずつ、合計11ブロック。Y方向は選択した段の下端から10または11ブロック。
- **黄色**：選択した区画の立ち位置を中心とした**幅1×高さ2ブロック**の枠。立ち位置Yから2ブロック上の境界まで、南北へ伸ばします。高さ11の段の立ち位置Yは段の下端+1です。
- Z方向は移動しながら掘る想定です。近くの16ブロック区間を表示します。標準の表示距離は南北それぞれ32ブロックで、描画範囲はチャンク境界にそろえて切り上げます。南北移動で表示する区間が切り替わっても、残る線の位置は変わりません。**線の端は採掘範囲の終点ではありません。**
- F3＋Gのように、ワールドのZ座標が16の倍数となる場所に断面の枠を表示します。この間隔は表示上の目盛りで、スキルの奥行きではありません。
- 初期設定では壁越しにも表示します。Pで壁越し表示、座標表示、南北の表示距離（8～128ブロックずつ）を変更できます。
- HUDには立ち位置、実際に掘るブロック座標、立ち位置との差を表示します。Excelのセル・A1などの列名は表示しません。F1でガイドも非表示になります。
- 固定位置からXまたはY方向へ256ブロックより遠ざかると、枠だけ描画を省略します。

10段モードの例：**X = −1487.5、足元Y = 71** の場合、掘るブロックは **X = −1493～−1483、Y = 71～80**。
枠はブロックの外側の境界 **X = −1493～−1482、Y = 71～81** に描画されます。
足元Yはプレイヤーの足の座標です。立っている床ブロックの座標は1つ下になります。

## 初期基準と設定の保存

初期基準X=-1487.5、間隔11は「第八回侵食大会集計.xlsx」の座標に基づきます。
実行時にはExcelや座標表を読み込まず、`基準X + 11 × 整数` で東西両方向の区画を計算します。
元の273列の座標は互換性確認用のテストデータとしてのみ保存しています。
Yは足元を含む段を優先し、ワールド上下端でも隣の段へ丸めません。
表示設定はゲーム環境の `config/shinshoku-outline.json` に保存します。

## ビルド

Java 17を使用します。

```sh
./gradlew build
```

Windowsでは `gradlew.bat build`。成果物は `build/libs/` に生成します。
`-sources.jar` はソース閲覧用で、ゲームに導入するファイルではありません。

ビルドには座標テストを含みます。全273列の接続、負のX座標、11×10のサイズ、正負のY段を検証します。
描画はFabricの `WorldRenderEvents.LAST` を使用しています。
1.1.0では、LASTイベントですでに適用されている視点回転を重ねず、カメラ相対の頂点を直接描画します。
API参照: https://maven.fabricmc.net/docs/fabric-api-0.77.0+1.18.2/net/fabricmc/fabric/api/client/rendering/v1/WorldRenderEvents.html
